# Arcada

Gestão de consultório odontológico: **pacientes, anamnese, odontograma, periodontograma, orçamento,
agenda por cadeira e financeiro** — num app que funciona em celular, tablet e computador, com o sistema
visual **vidro-orgânico**.

> **Em construção.** A v1 é só front-end: os dados vivem no navegador, atrás de uma camada
> (`src/dados/`) pensada para ser trocada por uma API depois. Todo dado de demonstração é fictício.
